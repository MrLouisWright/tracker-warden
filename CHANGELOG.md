# Changelog

## 1.0.0 (2026-10-14)

First release, by Louis Wright.

- Third-party detection in built HTML: scripts, inline SDK snippets, pixels, iframes, stylesheets, hints and media.
- Vendor database of 45 vendors with company, category, sells/shares and cookieless flags; unknown domains reported.
- Approved-vendor gate and JSON/CSV inventory export.
- Text/JSON/SARIF/Markdown output, `--fail-on`, exit codes 0/1/2, allowlist with expiry, severity overrides.
- Composite GitHub Action with job summary.
